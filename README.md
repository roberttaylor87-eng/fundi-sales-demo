# Fundi Sales — demo build

Swahili/English field sales tool for Tanzanian plumbing suppliers.
Single-file web app: open `index.html` in a browser, no build step.

**This is a demo build.** Prices are fictional, customers are invented, and
every phone number is deliberately unassignable so a demo tap cannot reach a
real person. Not for use with real customers.

Deployed from the working repository; this repo holds the built app only.
